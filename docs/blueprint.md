# **App Name**: Avelino & Davi Barbers

## Core Features:

- Landing Page: A visually striking landing page with a dark background and a clear call to action.
- Barber Profile Cards: Interactive profile cards for each barber, highlighting their individual styles and specializations.
- Dynamic Gallery: An image gallery showcasing haircuts with stylish captions revealed on hover.
- Direct WhatsApp Scheduling: One-click WhatsApp scheduling links for each barber to streamline booking.
- Interactive Map & Contact Buttons: Integrated map with direct access to WhatsApp and Instagram for easy communication.

## Style Guidelines:

- Background: A dark, charcoal gray (#333333) provides a modern and premium feel.
- Primary: A vibrant gold (#FFD700) suggests luxury and skill; useful for highlights.
- Accent: A lush green (#00FF00) nods to tropical vibes, perfect for Carlos' style.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and shorter texts, 'Inter' (sans-serif) for longer body content
- Rounded borders and subtle shadows add a modern, soft touch to the sharp street aesthetic.
- Smooth transitions and animations for an engaging, polished user experience.
- Use clean, modern icons that complement the typography and overall style.
